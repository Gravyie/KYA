# Visual Lab archive

The seventeen original interactive directions, including the unchanged Swarm reference. This is a separate Vite project; the product does not route to, import, or build it. Shared scene helpers are copied here deliberately so this reference remains portable.

```sh
cd reference/visual-lab
npm install
npm run dev
# http://127.0.0.1:5174/?d=swarm
```

Copy this folder into another project to keep exploring. Product APIs are not needed. Prototype links to the console/docs are historical; they do not connect to the product.
